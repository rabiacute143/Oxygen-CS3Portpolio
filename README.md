# Study Tips for Programming

## What This Project Is

This project is a collaborative guide that presents practical strategies for beginner programmers.

## Why It Exists

Programming can feel overwhelming when learners do not know how to organize practice or find reliable resources. This README gives beginners a simple place to find useful advice.

## How to Use It

Read the guide, choose a study strategy or learning resource, and practice consistently.

## Git Best Practices

- Commit small, complete changes with clear messages.
- Create a branch for each feature or fix.
- Pull the latest `main` branch before starting work.
- Review changes with a partner before merging.
- Never commit passwords, API keys, or personal data.

## Helpful Learning Resources

- [GitHub Docs](https://docs.github.com/) — guides for repositories, branches, pull requests, and collaboration.
- [Git Book](https://git-scm.com/book/en/v2) — a detailed reference for Git commands and workflows.
- [Visual Studio Code Documentation](https://code.visualstudio.com/docs) — help with editing, Source Control, and Git integration.
- [W3Schools Python Tutorial](https://www.w3schools.com/python/) — beginner Python lessons and examples.
